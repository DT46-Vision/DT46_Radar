# 裁判链路：无线与串口

来源：[`radar-referee-link` 技能](../.agents/skills/radar-referee-link/SKILL.md)。依据《RoboMaster 2026 机甲大师高校系列赛通信协议 V2.0.0》（2026-06-26）。官方 PDF 更新后以该技能为准，再同步本文。

雷达**只收**空中的信息波 / 干扰波；**不发射**。标记、密钥校验、双倍易伤经裁判串口发。串口只由一个进程写。

## 空中：信息波与干扰波（当前搁置）

官方信号发射源广播，雷达用 SDR 解调，约 10 Hz。

| 命令 | 内容 |
|---|---|
| `0x0A01` | 对方英雄、工程、3/4 号步兵、空中、哨兵坐标（厘米） |
| `0x0A02` | 对方血量 |
| `0x0A03` | 对方剩余允许发弹量 |
| `0x0A04` | 对方金币和占领状态 |
| `0x0A05` | 对方增益、哨兵姿态、存活 / 无敌 |
| `0x0A06` | 对方干扰波密钥，6 字节 ASCII |

这条链路**没有己方坐标**。

加密等级在常规链路 `0x020E`：开局 1，最高 3。可先解低等级干扰波，到 3 再切信息波。解调可参考 PnX / SHARK 开源，本仓库不重写发射端。

## 串口：标记 `0x0305`

雷达 → 服务器 → 己方选手端小地图。上限 **5 Hz**，数据段 48 字节：双方各 6 台车的 x、y（各 2 字节，厘米）。

顺序：对方英雄、工程、3 号、4 号、空中、哨兵，再己方同样六台。

己方某车 x、y 都为 0 时，视为本帧未发该车。超出边界显示在对应边缘。

标记进度由服务器以 1 Hz 用 `0x020C` 回传（2 字节），不是雷达自己填。组帧时对照协议原文核对位号。

## 串口：自主决策 `0x0121`

8 字节，雷达 → 服务器。

- **第 0 字节**：双倍易伤计数。开局 0；要触发时在当前值上加 1，须单调且每次只加 1。当时 `0x020E` 表明有机会才会生效。
- **第 1 字节**：指令类型；**第 2–7 字节**：6 位密钥。
  - 类型 `1`：更新己方密钥（开局，或对方破解成功导致己方干扰难度升级时）。
  - 类型 `2`：提交从 `0x0A06` 解出的对方密钥；提交后 10 秒内再提交无效。

停留区域、血量骤降等只决定**队伍何时**把第 0 字节加一；协议不规定策略。

## 串口：状态 `0x020E`

1 Hz，1 字节，服务器 → 雷达：剩余双倍易伤机会、对方是否正在被双倍易伤、己方加密等级、是否可改己方密钥等。细节位定义以协议原文与技能为准。
