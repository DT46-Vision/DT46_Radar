## 1. 雷达是什么（规则手册 3.7）

雷达可自主获取战场信息，经多机通信向己方机器人或裁判系统选手端发送信息，也可截获对方信息或反制对方空中支援。

| 关键特征 | 说明 |
|---|---|
| 初始区域 | 雷达基座 |
| 运行方式 | 自动运行；最多 1 个遥控器用于调试 |
| 多机通信 | 可向所有己方机器人发送；只能接收哨兵的数据 |

出场阵容含雷达；每场首局最低出场阵容至少 4 台机器人，不含雷达与飞镖系统（见规则手册阵容表）。

## 2. 雷达基座（规则手册 4.2.5）

- 用于放置雷达传感器与激光发射装置。
- 上端平台约 **3.4 m × 1.16 m**；平台中心与战场中心轴线对齐；距战场地面约 **2.5 m**；四周围栏高约 **1.1 m**。
- 旁有传感器数据线槽孔，按场地实际使用。
- 运算端 **220 V** 市电。平台上另有：
  - 官方显示器：仅 HDMI，**1920×1080**，可确认雷达运行状态；
  - 1 根 HDMI 线；
  - 1 个新国标 5 孔插座（单相两极与三极可同时接入），不可移动。

三分钟准备阶段内布置雷达于基座；上一场结束且雷达已撤出后，可提前把雷达放到基座上。

## 3. 特殊机制（规则手册 5.6.6）

功能三类：**雷达识别**、**雷达反制**、**雷达解析信息波**。

### 3.1 雷达识别与被标记进度 P

雷达识别双方地面机器人、空中机器人位置，把坐标发到裁判系统服务器。每台地面/空中机器人有被标记进度 **P ∈ [0, 150]**（初值 0）。

识别误差 **d**（雷达上报坐标与机器人实际平面坐标的直线距离）：

| 等级 | 条件 |
|---|---|
| 准确 | d &lt; 0.8 m |
| 半准确 | 0.8 m ≤ d &lt; 1.6 m |
| 错误 | d ≥ 1.6 m |

**x** 为当前标记影响值（初值 0）。判定频率由雷达发送频率决定。裁判系统每收到雷达数据或发生数据中断时：**先更新 x，再更新 P**。

| 标记状态 | x 更新 | P 更新 |
|---|---|---|
| 准确 | 上次为准确或半准确则 x = x + 1.0，否则 x = 1.0 | P = P + x；结果夹到 [0, 150] |
| 半准确 | 上次为准确或半准确则 x = x + 0.5，否则 x = 0.5 | 同上 |
| 错误 | 上次为错误/中断则 x = x − 0.8，否则 x = −0.8 | 同上 |
| 数据中断 | 累计 0.5 s 未收到数据，视为一次「错误」判定 | 同上 |

示例（规则原文）：5 Hz、连续准确时，0~1 s 内 P 依次约 1、3、6、10、15，约第 3 s 可达 120；之后连续错误或中断会使 P 加速下降。

**P 阈值与效果（地面机器人增益）：**

| 目标 | P | 小地图 | 增益 |
|---|---|---|---|
| 对方 | [0, 100) | 显示己方雷达上报位置 | 无 |
| 对方 | [100, 120) | 实际 UWB 位置 + 特殊标识 | **15% 易伤** |
| 对方 | [120, 150] | 实际 UWB 位置 + 特殊标识 | **20% 易伤** |
| 己方 | [0, 50) | 显示己方雷达上报位置 | 无 |
| 己方 | [50, 150] | 实际 UWB 位置 + 特殊标识 | 无 |

机器人被击毁后复活：**P 保留，当前 x 重置为 0**。

现场无线环境差或定位模块被大面积遮挡时，UWB 坐标可能间歇/持续漂移（规则提示）。

### 3.2 双倍易伤

- 雷达每累计使对方机器人处于易伤 **1 分钟**，获得 **1 次**触发「双倍易伤」的机会。
- **同时有多台机器人易伤时，时间不累加**（以规则手册 V2.2.0 中文表述为准）。
- 通过裁判系统主动发令消耗机会，使**当前所有来源于雷达的易伤数值翻倍**，持续 **30 秒**。
- 每局最多触发 **2 次**。

串口怎么发计数：见 [referee-link.md](referee-link.md)（`0x0121` / `0x020E`），此处不重复字节定义。

### 3.3 雷达反制空中（规则手册 5.6.3）

- 雷达可装激光发射装置，瞄准空中机器人的激光检测模块。
- **仅在对方空中机器人发起空中支援时**，己方雷达激光发射装置及其执行机构上电。
- 空中机器人有「被瞄准进度」P ∈ [0, 100]。达 **P0** 时发射机构锁定 **45 秒**，P 归零；锁定期间 P 不增长。
- 每局最多通过该机制锁定对方空中发射机构 **5 次**。
- 被瞄准难度随反制成功次数升高（难度一→二→三）：可检测区域缩小、P0 从 50 提到 100，后期可不主动发光。从第 4 次被反制成功起，空中可用金币解除并立即呼叫支援（规则细节见原文表 5-20）。

被瞄准进度：未照射时以 0.5/s 衰减；照射时按 0.1 s 周期累加（第 n 个 0.1 s 加 0.6×n）。不足 0.1 s 中断则计时归零。

### 3.4 雷达解析电磁波

- 双方雷达基座放置官方发射源：含对方队伍信息的**信息波**，以及相近频段**干扰波**。
- 红方广播源/干扰源在红方基座，载荷为**蓝方**信息；蓝方同理。
- 队伍可在雷达上装天线与解调电路；雷达**不发射**信息波/干扰波（工程约定亦见 referee-link）。

**调制（V2.2.0）：2-GFSK**（二进制高斯频移键控）；FSK 映射 0→−1，1→+1。

表 5-23 电磁波参数（摘自 V2.2.0）：

| 波源 | 中心频点 (MHz) | 带宽 (MHz) | 功率 (dBm) | 高斯滤波参数（摘要） |
|---|---|---|---|---|
| 红方广播源 | 433.2 | 0.54 | −60 | SPS:47, BT:0.35, Sample Rate:1M, Sensitivity:1.5628 rad/sample |
| 红方一级干扰 | 432.2 | 0.94 | −10 | Sensitivity:2.8194 |
| 红方二级干扰 | 432.5 | 0.86 | −10 | Sensitivity:2.5681 |
| 红方三级干扰 | 432.8 | 0.25 | −10 | Sensitivity:0.6517 |
| 蓝方广播源 | 433.92 | 0.54 | −60 | 同红方广播量级 |
| 蓝方一级干扰 | 434.92 | 0.94 | −10 | 同红方一级量级 |
| 蓝方二级干扰 | 434.62 | 0.86 | −10 | 同红方二级量级 |
| 蓝方三级干扰 | 434.32 | 0.25 | −10 | 同红方三级量级 |

信息波内容（对方）：各机器人位置、血量、剩余发弹量、当前增益、队伍剩余/总经济、各增益点占领状态。具体帧结构见《通信协议》；仓库摘要见 [referee-link.md](referee-link.md)。

干扰波：无具体战场信息，含对方自定义 **6 位**字母数字密钥。开局双方干扰均为**一级**；开局及己方干扰难度变化时密钥重置为随机值。解析成功并提交后，对方干扰难度升 1 级（己方基座干扰源难度升 1）。**当对方干扰难度高于己方时**，对方雷达即使准确标记己方，也不产生易伤、不积累双倍易伤进度。

附录 1 空口帧（摘要）：Access Code 信息波 `0x2F6F4C74B914492E`、干扰波 `0x16E8D377151C712D`（大端）；Header 4 字节含两份相同 Payload Length（15）；Payload 15 字节。信息波约 1400 byte/s（`0x0A01`–`0x0A05`，10 Hz）；干扰波约 1350 byte/s（含 `0x0A06`，10 Hz）。

## 4. 制作与安装（制作规范 2.4.7）

雷达由**运算平台端**与**传感器端**构成，须电缆连接；须能显示调试画面。

### 4.1 运算平台端

| 项目 | 限制 |
|---|---|
| 运行方式 | 全自动；最多 1 个遥控器用于调试 |
| 最大功率 | **750 W**（超限则该局市电切断，后果自负） |
| 供电 | 220 V / 50 Hz（中国大陆标准；其他地区可参照当地市电） |
| 最大伸展尺寸 | 长×宽×高不得大于 **600×350×600 mm** |
| 裁判系统 | 主控模块 + 电源管理模块（合计约 0.22 kg） |

- 三分钟准备阶段内放到基座附近指定台面；裁判系统**仅允许**装在运算平台端。
- **不得安装或使用无线设备**；无法拆除则须在 OS 中禁用。
- 主控与电源管理须稳固安装；裁判电源可与运算端共用或用指定电池。
- 建议与传感器端连接电缆预留至少 **5 m** 有效长度。
- 组委会只保证官方显示器与所供 HDMI 线可用，其余连接自理。

### 4.2 传感器端

| 项目 | 限制 |
|---|---|
| 最大伸展尺寸 | 长、宽不得超出放置平台；高度任意情况下不得大于 **1500 mm** |
| 最大供电电压 | **60 V** |
| 备注 | 建议支架高度 ≥ 1.2 m；连接线材不计入尺寸；无线电接收装置、激光发射装置可与主体分离，但长宽仍不得超出放置平台 |

- 须固定在雷达传感器支架上并置于雷达基座。
- **激光发射装置、无线接收装置须装在传感器端**。
- 自行设计支架以提高安装高度；支架须能安置于基座安装平面。
- 建议安装保护罩，防弹丸击打。
- 传感器端信号传输与电源自理。

### 4.3 光学与激光相关（制作规范摘录）

- 激光发射装置**仅可**安装在雷达传感器端；实测功率需小于 **1 mW**；波段不得大于 **730 nm**；不得改装激光产品。
- 地面机器人、雷达及附属设备不得安装非扫描式激光产品（空中等另有条例，以制作规范全文为准）。

### 4.4 正式比赛裁判接入（制作规范）

- 战场以有线方式把雷达接入战场网络与服务器。
- 场地人员把运算平台端电源管理模块的**主控接口**，经官方航空对接线接到有线接入点。
- 比赛中雷达无需自带主控，检录前取下调试用主控。
- 电源管理模块须外露、便于操作；主控接口**不可**连接任何设备；航空线理顺易拉出。
- 飞镖系统、雷达使用组委会安装于场地的主控模块。

雷达被罚下/驱逐时：裁判串口断开，激光发射装置及其执行机构断电（规则手册判罚相关表述）。
