# 修改后主动报告

## 必须遵守

1. MUST 在本次修改或实机检查结束后主动报告。中途停下也报告已经发生的改动。
2. MUST 每项行为变化单独列出，包括用户没点名但这次一起做的变化。
3. MUST 写清改了什么、为什么、影响、验证状态。未验证写「未验证」。
4. MUST 单独列出偏离原方案的部分和未完成事项。

## 报告模板

- 文件/位置：
- 改了什么：
- 为什么：
- 影响：
- 验证：已验证 / 未验证 / 验证失败。附方法、结果和适用范围。

最后单独列出：

- 偏离原方案：无，或逐项说明。
- 未完成事项：无，或逐项说明。

实机流程由 [verify-to-conclusion](../verify-to-conclusion/SKILL.md) 负责。报告不能代替 [align-before-act](../align-before-act/SKILL.md) 要求的事前确认。
