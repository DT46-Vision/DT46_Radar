# 一个事实只写一处

1. MUST 在创建或编辑文档时遵守：一个事实只设一个维护来源。
2. MUST 先查 [.claude/conventions/docs.md](../../../.claude/conventions/docs.md)。已有入口只改那里，别处留链接。
3. MUST NOT 为同一选型、协议字段或实测数字再写一份正文。

README 只保留本仓库是什么和待确认项。驱动约束、包边界、裁判命令分别留在对应技能。`Livox_MID-70` 里的实测数字不抄进本仓库。

用户明确要的审阅快照可以复制，但要标明来源和快照用途，不成为新的维护入口。
