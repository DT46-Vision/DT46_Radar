# 按范围查资料，用证据判断

1. MUST 在用户要求查资料，或继续行动会靠猜测时使用本技能。
2. MUST 先写明问题、允许的范围、需要的证据、停在哪里。能读到目录不等于可以整库扫。
3. MUST 先定位再读。只沿当前问题扩展。
4. MUST 优先第一手材料：本仓库技能、官方协议 PDF、对应仓库的源码。转述不能代替原文。
5. MUST 把来源事实、推断和缺口分开。冲突时两列都留下，不默选方便的一方。

## 检索

本机 shell 是 bash。先收窄目录，再 `rg -n`。默认不扫 `.git`、`build`、`install`、随包的第三方源码树，除非问题就在那里。

```bash
rg -n -F -g '*.md' -g '*.cpp' -g '*.h' -e '关键词' -- src
```

退出码 0 是有匹配，1 是该范围内没有，其他是搜索失败。无匹配要写明查过的目录和文件类型，不写成「仓库里不存在」。

用户给了网址就先读该页。读不到就说明，不用记忆补成已经读过。
